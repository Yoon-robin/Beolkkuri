# Security Policy

If you find a security issue, please tell us privately first.

## Reporting a Vulnerability

Please **do not** open a public issue for a security problem. Report it through [GitHub's private vulnerability reporting](https://github.com/Yoon-robin/Beolkkuri/security/advisories/new) instead, so it can be fixed before it is [disclosed](https://en.wikipedia.org/wiki/Responsible_disclosure).

## Supported Versions

Only the latest release is supported.
