자주 묻는 질문

돈 내야 하나요?
아니요, 무료예요. 코드도 GitHub에 전부 공개돼 있어요.
어떤 컴퓨터에서 돌아가요?
맥과 윈도우 둘 다 돼요. 맥은 애플 실리콘(M1 이상)이면 macOS 13 Ventura 이상, 인텔 맥이면 macOS 10.12 이상이 필요해요. 윈도우는 64비트 윈도우 10(1809 이상)이나 윈도우 11이면 돼요. 윈도우 버전은 새로 나와서, 이상한 점이 있으면 알려 주세요.
시작을 눌러도 캐릭터가 안 움직여요
맥이라면 거의 항상 권한 문제예요. 앱의 시작 가이드에서 손쉬운 사용과 화면 기록에 초록 체크가 있는지 보고, 켠 다음에는 터미널을 완전히 껐다가(⌘Q) 다시 열어 주세요. 윈도우라면 디스플레이 배율이 100%인지, 로블록스를 관리자 권한으로 실행하지 않았는지 확인해 주세요.
업데이트는 어떻게 해요?
앱 왼쪽 아래의 업데이트 확인을 누르거나, 설치 명령을 한 번 더 붙여 넣으면 돼요. 설정은 그대로 남아요.
처음부터 다시 설치하고 싶어요
매크로 전용 환경을 지운 다음 설치 명령을 다시 붙여 넣으면 돼요.
맥: rm -rf ~/beolkkuri-env
윈도우: Remove-Item -Recurse -Force $HOME\beolkkuri-env
매크로 써도 괜찮나요?
매크로 사용에 대한 책임은 사용자에게 있어요. 게임 규칙을 확인하고 본인 판단으로 사용해 주세요. 벌꿀이는 Onett, 비 스웜 시뮬레이터, Roblox와 관련이 없어요.
