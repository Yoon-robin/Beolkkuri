FAQ

자주 묻는 질문

돈 내야 하나요?
아니요, 완전히 무료예요. 코드도 GitHub에 전부 공개돼 있어요.
윈도우에서도 되나요?
RobinMacro는 맥 전용이에요. 애플 실리콘(M1 이상)은 macOS 13 Ventura 이상, 인텔 맥은 macOS 10.12 이상이 필요해요.
시작을 눌러도 캐릭터가 안 움직여요
거의 항상 권한 문제예요. 앱의 시작 가이드에서 손쉬운 사용과 화면 기록이 초록 체크인지 확인하고, 켠 다음에는 터미널을 완전히 껐다가(⌘Q) 다시 열어 주세요.
업데이트는 어떻게 해요?
앱 왼쪽 아래의 업데이트 확인을 누르거나, 설치 명령을 한 번 더 붙여넣으면 돼요. 내 설정은 그대로 남아요.
처음부터 다시 설치하고 싶어요
터미널에서 rm -rf ~/robin-macro-env 를 실행한 뒤 설치 명령을 다시 붙여넣으세요.
매크로 써도 괜찮나요?
매크로 사용에 대한 책임은 사용자에게 있어요. 게임 규칙을 확인하고 본인 판단으로 사용해 주세요. RobinMacro는 Onett, 비 스웜 시뮬레이터, Roblox와 관련이 없어요.
