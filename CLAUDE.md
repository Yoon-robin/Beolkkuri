# RobinMacro

Bee Swarm Simulator macro for macOS with a React + shadcn/ui interface. It started as a fork of Fuzzy Macro (itself built on Existance Macro), was fully rebranded, and was given a new UI for Korean users who don't code. Korean is the default UI language, with an English toggle. Talk to the owner (Yoon-robin) in Korean.

## Layout

```
src/              Python macro (macOS only). main.py starts it; gui.py exposes functions to the UI via eel.
  modules/        macro logic, settings (misc/settingsManager.py), updater (misc/update.py), AI models (misc/modelManager.py)
  webapp/         BUILT UI — generated by `pnpm --dir ui build`, committed so users get it. Never edit by hand.
ui/               React 19 + Vite 6 + TypeScript + Tailwind v4 + shadcn/ui (radix, nova preset) source
  dev/            dev_server.py (HTTP backend for the browser), eel_harness.py (serves the build through real eel)
  scripts/        extract-schema.mjs (one-off migration, see "Settings schema")
paths/, settings/ movement paths and gather patterns used by the macro
install.sh        one-line installer: downloads latest release (or main) into ~/RobinMacro, runs install_dependencies.command
install_dependencies.command / run_macro.command   macOS installer and launcher (bash, LF, must stay executable)
docs/             Korean help pages linked from the app and README
```

## Developing (any OS)

Needs Node 20+, pnpm, Python 3.9+.

```bash
pnpm --dir ui install
python ui/dev/dev_server.py     # 127.0.0.1:8765, real settingsManager + stubs for macro calls
pnpm --dir ui dev               # http://localhost:5173 (proxies /__py to the dev server)
```

`.claude/launch.json` has both as `robinmacro-backend` / `robinmacro-ui` for the preview tools.

- **The dev server reads and writes the real `settings/profiles/default` files** (created from defaults on first run; gitignored). Restore anything you toggle while testing.
- Macro-only calls (start/stop/tools/updates/permissions) are stubbed in `STUBS` in `ui/dev/dev_server.py`. Add a stub when the UI calls a new `gui.py` function, matching the real return shape. `DEV_PERMISSIONS` fakes Screen Recording as off until its "켜기" button is pressed.
- Before committing UI changes: `npx tsc -b` in `ui/`, then `pnpm --dir ui build`, and commit `src/webapp` together with the source. The in-app updater ships whatever is in `src/webapp`.
- After a build, check that only `bridge.js` contains literal `eel.expose(` (eel scans web files for that text to learn JS function names).
- Hot reload sometimes logs "useTheme must be used inside ThemeProvider"; a full reload clears it.

## How the UI talks to Python

- JS → Python: `callPy(name, ...args)` in `ui/src/lib/py.ts` calls `eel.name(...)()` in the app, or POSTs to `/__py/name` in dev. Typed shortcuts live in `py`.
- Python → JS: `ui/public/bridge.js` is a plain, unbundled script that defines and `eel.expose`s global functions (`log`, `loadInputs`, `toggleStartStop`, `getElementProperty`, ...). They forward to React handlers registered with `usePythonEvent` (`ui/src/lib/bridge.ts`). Add new Python-callable functions there.
- The app window is Chrome `--incognito`, so localStorage does not survive restarts. Persistent UI prefs go into general settings (`ui_language`, `ui_theme`).

## Settings schema

- `ui/src/schema/legacy-schema.json` (65 sections / 246 settings) describes every standard setting row: id, type, options, save target. It was extracted once from the old jQuery UI with `ui/scripts/extract-schema.mjs` and then **edited by hand** (rebrand wording). Edit the JSON directly; don't re-run the extractor.
- `saveTargetOf(def)` decides profile / general / field / custom saving. Dropdown values are saved lower-cased like the legacy UI; numeric text boxes save strings (0 when empty). **Never change setting ids or value formats**, because Python reads them.
- Korean text for the schema: `ui/src/i18n/settings-ko.json` (settings by id; sections and options by English label; id-less separators as `sep:<title>`).
- Pages render schema sections with `SchemaSections` and customise them with `overrides` (`ui/src/components/settings/schema-section.tsx`).

## UI conventions

- **Strings:** app-wide strings go in `ui/src/i18n/ui.ts`; page strings go in a local `PageStrings` table read with `useStrings`. Always keep ko and en in sync. Korean copy uses natural, friendly 해요체 and stays short.
- **Motion utilities** in `ui/src/index.css`:
  - `.rm-page` staggers a page's children automatically.
  - `.rm-stagger`, `.rm-shimmer`, `.rm-glow`, `.rm-pop` and `.rm-flash` are opt-in.
  - There is a global `prefers-reduced-motion` override.
  - Theme switching uses a view-transition circle (`ui/src/lib/theme.tsx`).
- **Search palette** (Ctrl/⌘+K, `components/command-palette.tsx`): it jumps with `goToTarget` (`lib/focus.ts`). Pages with sub-tabs call `useTabRequest(page, setTab)`, and rows call `useFocusTarget`. A new sub-tab or custom row needs the same hooks, plus an entry in the palette's sub-tab table.
- **Run state:** `state/run-state.tsx` handles polling, the session timer and the start/stop toasts.
- **Permissions:** `state/permissions.ts` polls `getPermissionStatus` in `gui.py`.
- **Components:** use the shadcn components in `ui/src/components/ui` and Tailwind. Don't add dependencies casually.

## Brand rules

The owner asked for no trace of the old name. "Fuzzy"/"fuzz" may appear only in:
- `LICENSE`: the Fuzzy Team BSD-3 and Existance BSD-4 notices are legally required. Also the README credit line required by the Existance license.
- `modelManager.MODELS_REPO`: the default is `Fuzzy-Team/fuzzymacroaimodels`. That repo has no license, so it can't be re-hosted; it can be overridden with `ROBINMACRO_MODELS_REPO`.
- Game terms and libraries: the bee "fuzzy"/"gifted_fuzzy", "Fuzz Bombs" tokens, `fuzzywuzzy`, and the word "fuzzy match".

The Discord bot prefix is `robin!`. Discord Rich Presence is off until `ROBINMACRO_DISCORD_APP_ID` is set.

## Repo housekeeping

- `.gitattributes` forces LF. Windows has `core.autocrlf=true`, so expect CRLF warnings; they are harmless.
- `*.command` files must keep mode 100755. When adding one from Windows: `git update-index --chmod=+x <file>`.
- Version: `ui/public/version.txt`, copied to `src/webapp/version.txt` by the build. `src/modules/misc/update.py` compares it with GitHub releases of `Yoon-robin/RobinMacro`. `install.sh` installs the latest release zipball, or `main` if there are no releases.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
